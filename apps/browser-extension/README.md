# 汽车直播盯播浏览器扩展

用于试点阶段采集当前直播标签页的声音，并在懂车云店直播大屏中同步实时指标。

## 能力

- 不读取、不保存、不上传登录 Cookie；
- 采集当前标签页音频，转换为 16 kHz 单声道 PCM；
- 将音频发送到既有 `/ws/audio/{session_id}` 实时通道；
- 捕获懂车云店直播大屏的指标接口响应；
- 切换同一标签页中的直播间时无需重启；
- 切换到其他标签页时，在扩展中再次点击“采集当前标签页”。
- 可直接粘贴懂车云店直播链接，扩展会自动查找或创建盯播场次。

## 本地安装

1. Chrome/Edge 打开扩展管理页；
2. 开启“开发者模式”；
3. 选择“加载已解压的扩展程序”；
4. 选择本目录 `apps/browser-extension`；
5. 安装后刷新已打开的懂车云店直播大屏页面；
6. 可在盯播平台创建场次并复制场次 ID，也可直接复制懂车云店直播链接；
7. 打开直播标签页，点击扩展图标，填写服务器地址和场次 ID 或直播链接；
8. 点击“采集当前标签页”。

如果扩展提示“尚未抓到”，请刷新一次懂车云店直播大屏。扩展会缓存页面最近返回的指标，并在开始采集后自动补传；弹窗会显示最后一次上传时间或具体错误。

如果扩展提示“连续8秒未检测到声音”，请确认直播画面正在播放、播放器和浏览器标签页均未静音，并且电脑可以实际听到主播声音，然后停止并重新采集。

正式批量部署时应发布为签名扩展，或通过企业浏览器策略统一安装和更新。
