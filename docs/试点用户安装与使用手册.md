# 智播运营控制台试点用户安装与使用手册

> 适用对象：首次参与试点的直播优化师、运营同事  
> 适用系统：Windows 10 / Windows 11  
> 支持浏览器：Google Chrome 116 及以上版本、Microsoft Edge 116 及以上版本  
> 浏览器扩展：汽车直播盯播助手 `v0.2.1`  
> 工作台地址：[http://124.220.147.243/](http://124.220.147.243/)  
> 文档版本：`v1.0`  
> 更新日期：2026 年 8 月 13 日

---

## 1. 试点说明

智播运营控制台用于直播过程中的实时辅助，当前试点版本主要提供以下能力：

- 采集懂车云店直播大屏所在浏览器标签页的音频；
- 将直播声音实时转写为文字；
- 同步懂车云店大屏中的实时监控数据；
- 根据转写与监控数据生成实时诊断、建议动作和推荐话术；
- 一个账号管理多个直播场次，并查看多直播间汇总；
- 保存每名优化师自己的个性化语料库；
- 直播结束后手动结束场次，并生成整场复盘。

本次试点采用网页工作台加浏览器扩展的方式。同事电脑不需要安装 Python、Node.js、数据库或其他开发环境，只需要：

1. 一台可以正常联网的 Windows 电脑；
2. Chrome 或 Edge 浏览器；
3. 已收到并解压的“汽车直播盯播助手”扩展文件夹；
4. 已通过管理员审核的智播工作台账号；
5. 可以正常登录懂车云店的业务账号。

> 重要提示：智播工具是运营辅助工具。实时建议需由使用者结合直播实际情况判断，不应代替业务人员作最终决策。

## 2. 开始前准备

### 2.1 确认浏览器版本

#### Chrome

在地址栏输入：

```text
chrome://settings/help
```

确认版本不低于 `116`。浏览器通常会在该页面自动检查更新，更新完成后按提示重新启动浏览器。

#### Edge

在地址栏输入：

```text
edge://settings/help
```

确认版本不低于 `116`。

### 2.2 解压扩展文件

将收到的扩展压缩包解压到一个长期固定的位置，例如：

```text
C:\智播助手\browser-extension
```

打开该文件夹后，应能直接看到以下文件：

```text
manifest.json
popup.html
popup.js
service-worker.js
bridge-main.js
content.js
offscreen.html
offscreen.js
```

如果打开文件夹后里面还有一层同名文件夹，应继续进入下一层，直到能直接看到 `manifest.json`。

> 安装完成后不要删除、重命名或移动这个文件夹。浏览器扩展依赖该目录运行；移动后需要重新安装。

## 3. 首次安装浏览器扩展

### 3.1 Chrome 安装方法

1. 打开 Chrome。
2. 在地址栏输入 `chrome://extensions` 并回车。
3. 打开页面右上角的“开发者模式”。
4. 点击左上角“加载已解压的扩展程序”。
5. 选择刚才解压的扩展目录，例如：

   ```text
   C:\智播助手\browser-extension
   ```

6. 页面中出现“汽车直播盯播助手”卡片即表示安装成功。
7. 确认卡片右下角开关处于开启状态。

### 3.2 Edge 安装方法

1. 打开 Edge。
2. 在地址栏输入 `edge://extensions` 并回车。
3. 打开页面左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择扩展目录。
6. 确认“汽车直播盯播助手”已经启用。

### 3.3 将扩展固定到工具栏

为避免直播时找不到扩展，建议将其固定到浏览器工具栏：

1. 点击浏览器地址栏右侧的拼图图标“扩展程序”。
2. 找到“汽车直播盯播助手”。
3. 点击旁边的图钉图标。
4. 固定后，浏览器右上角会长期显示扩展图标。

### 3.4 安装后的必要操作

如果安装扩展前已经打开了懂车云店大屏，请在安装完成后刷新一次懂车云店页面。未刷新时，扩展可能无法抓取该页面的数据。

1. 打开工作台：[http://124.220.147.243/](http://124.220.147.243/)。

## 5. 每场直播的标准操作流程

建议严格按照以下顺序操作：

```text
登录懂车云店
    ↓
打开对应直播大屏
    ↓
登录智播工作台并创建场次
    ↓
复制场次 ID
    ↓
在直播大屏标签页启动扩展
    ↓
核对音频与监控数据状态
    ↓
开始实时盯播
    ↓
直播结束后停止采集
    ↓
结束场次并生成复盘
```

### 5.1 打开懂车云店直播大屏

1. 登录懂车云店。
2. 进入需要监控的直播间。
3. 打开直播实时大屏页面。
4. 确认页面中能看到实时在线人数、累计观看人数、消耗等数据。
5. 保持这个标签页打开，不要关闭。

### 5.2 创建智播场次

1. 在另一个浏览器标签页打开智播工作台。
2. 进入“场次管理”。
3. 在“新建监控场次”中填写：

   - 场次名称：必填，建议格式为“日期 + 直播间 + 场次”，例如“8月13日-iCAR武汉-晚场”；
   - 直播平台：选择“懂车云店”；
   - 直播间链接：建议填写当前懂车云店直播大屏的完整地址；
   - 直播间备注：选填，可填写主播、门店或投放计划名称。

4. 点击“创建场次”。
5. 进入刚刚创建的场次。
6. 点击“复制场次ID”。

> 每场直播应建立一个新的场次。不要重复使用已经结束的场次 ID。

### 5.3 启动浏览器扩展采集

1. 切换回懂车云店直播大屏所在标签页。
2. 点击浏览器右上角的“汽车直播盯播助手”图标。
3. 检查“服务器地址”是否为：

   ```text
   http://124.220.147.243
   ```

4. 在“场次ID或直播链接”中粘贴刚才复制的完整场次 ID。
5. 点击“采集当前标签页”。
6. 浏览器可能提示正在共享当前标签页，此时保持当前选择即可。

> 必须在懂车云店直播大屏标签页中打开扩展并启动采集。若在智播工作台、搜索页或其他标签页启动，会采集错误的标签页声音，也无法获得大屏指标。

### 5.4 确认采集成功

扩展启动后，需要同时检查音频和监控数据。

#### 音频状态

满足以下条件表示音频通道正常：

- 扩展状态显示“正在采集当前直播标签页”或类似已连接信息；
- 状态圆点为绿色；
- 直播有声音时，实时音量条会变化；
- 工作台“音频采集”显示“浏览器扩展已连接”。

#### 监控数据状态

满足以下条件表示懂车云店数据采集正常：

- 扩展显示“监控数据：已上传 HH:mm:ss”；
- 工作台的数据观测区域开始显示实时指标；
- 指标的更新时间会持续变化。

如果扩展显示：

```text
监控数据：尚未抓到，请刷新懂车云店大屏
```

请执行：

1. 先保持扩展采集开启；
2. 刷新懂车云店直播大屏页面；
3. 等待页面数据重新加载；
4. 再次打开扩展查看状态；
5. 确认变为“监控数据：已上传”。

#### 转写状态

主播正常说话后，工作台“实时转写”区域应持续增加文字。首次结果可能需要短暂等待。

### 5.5 直播过程中使用工作台

直播过程中主要关注以下区域：

- 实时诊断：查看当前直播存在的风险或异常；
- 建议动作：查看优化师可以立即执行的调整；
- 推荐话术：提供给主播参考使用；
- 数据观测：查看实时在线、观看、互动、转化等指标；
- 实时转写：核对主播当前讲解内容；
- 多直播间总览：当本人同时管理多个场次时查看整体状态。

工作台会自动刷新数据，通常不需要手动刷新整个网页。如果页面提示实时通道断开，会自动尝试重新连接。

> 不建议在直播中频繁刷新智播工作台。刷新工作台不会停止扩展采集，但会暂时中断页面显示并重新建立连接。

## 6. 同时监控多个直播间

当前扩展最多支持同时采集 3 个直播标签页。每个直播间都必须对应独立场次。

操作方法：

1. 为第一个直播间创建场次 A，并在直播标签页 A 中启动扩展；
2. 为第二个直播间创建场次 B，并在直播标签页 B 中启动扩展；
3. 如有第三个直播间，按相同方式创建场次 C；
4. 在扩展的“并发采集任务”中检查当前正在采集的直播间；
5. 在工作台“多直播间总览”中查看所有正在进行的场次。

注意事项：

- 不要把多个直播间绑定到同一个场次 ID；
- 必须在每个直播间自己的标签页中分别启动扩展；
- 同一场次不能由两台电脑或两个标签页同时建立音频采集；
- 电脑性能或网络不足时，应减少同时采集数量；
- 关闭直播标签页会停止该标签页的采集任务。

## 7. 结束直播与生成整场复盘

直播正式结束后，按以下顺序操作。

### 7.1 停止浏览器采集

1. 回到对应的懂车云店直播大屏标签页。
2. 打开“汽车直播盯播助手”。
3. 点击“停止”。
4. 确认该直播间从“并发采集任务”中消失。

停止后，服务器会完成该场直播录音文件的封装。

### 7.2 结束智播场次

1. 回到智播工作台中的对应场次。
2. 确认转写和指标已经停止增加。
3. 点击页面上方“结束场次”。
4. 确认场次状态变为“已结束”。

> “结束场次”代表该场直播已经正式完成。结束后不要继续使用这个场次 ID 采集新的直播。

### 7.3 生成整场复盘

场次结束后，工作台会进入复盘区域：

1. 等待系统自动生成复盘；
2. 如果未自动生成，可以点击“生成复盘”；
3. 生成过程中请耐心等待，不要连续重复点击；
4. 生成完成后查看整场摘要、关键指标、问题和改进建议；
5. 如需重新生成，可点击“重新生成”。

复盘由整场转写、实时指标和 AI 诊断综合生成。若某场直播缺少转写或指标，复盘的完整度也会受到影响。

## 8. 个性化语料库的使用

每名优化师拥有独立的语料库。已启用的语料会用于约束和优化该账号的实时提醒及推荐话术。

进入工作台左侧“我的语料库”，可以：

- 手动新增一条语料；
- 编辑已有语料；
- 启用或停用语料；
- 删除不再使用的语料；
- 上传已有文件，系统自动整理为 Markdown 语料。

建议优先录入以下内容：

- 直播间合规要求；
- 品牌统一表达；
- 车型核心卖点；
- 常见异议处理；
- 线索转化话术；
- 监控指标异常时的处置规则；
- 不允许出现的承诺、价格或敏感表述。

注意事项：

- 只上传已获授权的内部业务资料；
- 不要上传账号密码、客户身份证号、手机号清单等敏感信息；
- 内容冲突时，应及时停用或删除旧语料；
- 语料更新后只影响之后生成的新提醒，不会修改已经生成的历史内容。

## 9. 常见问题处理

### 9.1 无法打开工作台

现象：浏览器提示无法访问、连接超时或 `Failed to fetch`。

处理顺序：

1. 确认电脑网络正常；
2. 直接访问 [http://124.220.147.243/](http://124.220.147.243/)；
3. 注意地址是 `http://`，不是 `https://`；
4. 换一个网络测试，例如手机热点；
5. 若其他同事也无法访问，联系管理员检查服务器。

### 9.2 注册后不能登录

可能原因：账号仍在等待管理员审核。

处理方法：联系管理员确认账号是否已设置为“启用”。不要重复注册多个账号。

### 9.3 找不到浏览器扩展

处理方法：

1. 打开浏览器扩展管理页；
2. 检查“汽车直播盯播助手”是否存在并启用；
3. 如果扩展卡片报错，先点击“重新加载”；
4. 如果扩展目录已被移动或删除，重新选择正确目录安装；
5. 将扩展重新固定到浏览器工具栏。

### 9.4 扩展显示已连接，但没有转写

处理顺序：

1. 确认直播标签页本身可以听到声音；
2. 打开扩展，观察音量条是否变化；
3. 确认是在正确的直播大屏标签页启动采集；
4. 点击“停止”，然后重新点击“采集当前标签页”；
5. 确认场次 ID 与当前工作台场次一致；
6. 等待主播继续讲话，观察是否出现新转写；
7. 仍无结果时记录时间、场次 ID 和扩展状态并反馈管理员。

### 9.5 有转写，但没有监控指标

这说明音频通道正常，但懂车云店数据尚未被抓取。

处理顺序：

1. 确认当前页面是懂车云店直播大屏，而不是直播列表页；
2. 确认大屏页面自身能看到实时指标；
3. 保持扩展采集开启，刷新懂车云店大屏；
4. 等待页面加载完成；
5. 打开扩展，查看是否显示“监控数据：已上传”；
6. 如果显示“上传失败”，完整记录扩展显示的错误文字；
7. 回到工作台等待约 10 秒。

### 9.6 工作台指标不再更新

处理顺序：

1. 打开扩展，检查最后上传时间是否继续变化；
2. 如果最后上传时间停止，刷新懂车云店大屏；
3. 如果扩展已断开，停止后重新采集；
4. 如果扩展正常而工作台不更新，点击工作台“刷新”；
5. 记录异常开始时间并反馈管理员。

### 9.7 提示该场次已有其他音频采集连接

同一个场次已经被另一台电脑、另一个标签页或未关闭的旧任务占用。

处理方法：

1. 找到原来采集该场次的标签页并停止；
2. 检查是否在其他电脑启动了同一场次；
3. 不要创建多个采集任务连接同一个场次；
4. 如果原任务已经不存在但仍提示占用，联系管理员处理。

### 9.8 采集一段时间后自动停止

可能原因包括标签页被关闭、浏览器休眠、电脑进入睡眠、网络中断或直播页面停止播放。

建议：

- 直播期间不要让电脑进入睡眠；
- 不要关闭正在采集的直播标签页；
- 不要退出整个浏览器；
- 保持网络稳定；
- 发现停止后立即重新连接，并记录中断时间。

### 9.9 实时建议与直播实际情况不符

1. 不要直接照读明显不合适的内容；
2. 记录问题发生时间和具体建议；
3. 检查当前场次是否绑定正确；
4. 检查个人语料库是否有冲突或过期内容；
5. 在试点反馈表中说明期望的正确提醒方式。

### 9.10 扩展升级方法

收到新版扩展文件后：

1. 直播未采集时再进行升级；
2. 解压并替换原扩展目录中的文件；
3. 打开 `chrome://extensions` 或 `edge://extensions`；
4. 找到“汽车直播盯播助手”；
5. 点击“重新加载”；
6. 刷新已经打开的懂车云店大屏；
7. 重新启动采集并核对状态。

> 不要在直播采集过程中替换扩展文件或点击重新加载，否则当前采集会中断。

## 10. 每场直播开播前检查表

建议在正式开播前 5–10 分钟完成。

```markdown
- [ ] 电脑网络正常
- [ ] Chrome/Edge 可以正常使用
- [ ] 懂车云店账号已登录
- [ ] 正确的直播大屏已经打开
- [ ] 智播工作台可以访问
```

## 13. 数据与安全说明

### 13.1 浏览器扩展采集内容

扩展用于采集：

- 用户主动选择的直播标签页音频；
- 懂车云店直播大屏接口返回的监控指标；
- 当前直播页面地址及用于匹配的场次 ID。

扩展不会主动读取、保存或上传懂车云店登录 Cookie。

### 13.2 使用要求

- 仅用于公司已授权的直播业务试点；
- 不要采集无关网页、会议、私人音频或个人账号页面；
- 不要向非试点人员发送工作台账号和内部数据；
- 不要共用账号，每名优化师使用自己的账号；
- 密码不得写在扩展目录或发到公共群；
- 电脑离开本人控制时，应锁屏或退出账号；
- 发现账号异常登录或数据归属错误时立即联系管理员。

### 13.3 试点期间禁止操作

- 不要删除或修改扩展目录中的文件；
- 不要修改扩展默认服务器地址；
- 不要在扩展采集期间关闭直播标签页；
- 不要把同一个场次 ID 分配给多个直播间；
- 不要在直播进行中升级或重新加载扩展；
- 不要将管理员账号、服务器密钥或数据库文件交给普通试点用户。

## 附录：最短操作速查

### 开播

```text
打开懂车云店直播大屏
→ 工作台创建场次
→ 复制场次 ID
→ 回到直播大屏标签页
→ 打开扩展并粘贴场次 ID
→ 点击“采集当前标签页”
→ 确认音量条变化
→ 确认“监控数据：已上传”
→ 回工作台确认转写和指标
```

### 下播

```text
扩展点击“停止”
→ 工作台点击“结束场次”
→ 等待或手动点击“生成复盘”
→ 检查复盘
→ 填写试点反馈
```

### 没有监控数据

```text
确认当前是懂车云店直播大屏
→ 保持扩展采集开启
→ 刷新懂车云店大屏
→ 查看扩展最后上传时间
→ 等待工作台刷新
```

### 没有转写

```text
确认直播标签页有声音
→ 查看扩展音量条
→ 核对场次 ID
→ 停止并重新采集
→ 仍无结果则截图反馈
```
